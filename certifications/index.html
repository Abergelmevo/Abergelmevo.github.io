Obtenuejuillet 2026

CCNA

Cisco

La certification réseau de référence de Cisco, niveau Associate : elle valide la mise en place, l'exploitation et le dépannage d'un réseau d'entreprise, du câblage jusqu'à la sécurité et l'automatisation.

Six domaines d'examen · valable trois ans

Domaines de l'examen

  • Connectivité IP : routage statique, OSPF, redondance de passerelle25 %
  • Fondamentaux : adressage IPv4 et IPv6, TCP/UDP, câblage20 %
  • Accès réseau : VLAN, trunks, EtherChannel, Spanning Tree, Wi-Fi20 %
  • Sécurité : ACL, DHCP snooping, AAA, VPN IPsec, WPA315 %
  • Services IP : NAT, DHCP, DNS, NTP, SNMP, syslog, SSH10 %
  • Automatisation : SDN, API REST, JSON, Ansible10 %
